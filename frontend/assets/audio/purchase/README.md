# Sonidos de compra

Seis muestras locales de [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), bajo CC0. `LICENSE.txt` conserva la licencia original y `sources.json` identifica cada archivo y su SHA-256.

`receipt.ogg` confirma la respuesta del servidor; `arrival.ogg` acompaña la entrada; `energy.ogg` la absorción; `lock.ogg` el cierre; `tick.ogg` los tres movimientos; `success.ogg` la confirmación final.

Se reduce temporalmente la música sin detenerla, se detienen las voces Pokémon previas y se limita la superposición a tres muestras. Silenciar corta también las muestras que estén sonando. Al terminar, saltar o abandonar la presentación se liberan las voces y la reducción de música. Un fallo de sonido no invalida una compra.
